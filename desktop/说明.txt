DeepSeek Harness 客户端 —— 安装说明

【为什么自带 Node.js 运行时？】
本客户端基于 DeepSeek Harness，它的核心引擎运行在 Node.js 上。
为了让「安装后即可使用、无需单独配置开发环境」，本安装包已内置
Node.js 运行时。安装完成后直接打开就能用，不需要你自己安装 Node。

【支持的系统】
- Windows 10（64 位）及更高版本
- Windows 11（64 位）
- 仅支持 64 位（x64）系统，不支持 32 位（x86）系统

【使用提示】
- 首次启动会初始化运行环境，请耐心等待片刻。
- DeepSeek API Key 请在客户端「设置 → API 管理」中配置。
- 快捷键 Ctrl+Alt+D 可呼出/隐藏窗口。
