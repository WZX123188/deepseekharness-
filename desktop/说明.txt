DeepSeek Harness 客户端 —— 安装说明

【完全独立 · 不碰你已有的东西】
本客户端是「完全独立」版本：内置了完整的 DeepSeek Harness 运行时，
数据也存放在客户端自己的目录里，绝不修改、不依赖你电脑上已有的
Node.js、网页版 DSH 或它们的配置。安装/解压即用，互不影响。

【便携版（绿色版）说明】
便携版（zip）解压到任意文件夹即可使用，数据保存在程序目录下的
data\ 子目录里，整个文件夹拷到 U 盘 / 移动硬盘 / 别的电脑都能直接用。
安装版（exe）的数据则保存在系统的用户数据目录（%APPDATA%\DeepSeekClient）。

【为什么自带 Node.js 运行时？】
本客户端基于 DeepSeek Harness，其核心引擎运行在 Node.js 上。
为让「安装后即可使用、无需单独配置开发环境」，本安装包已内置
Node.js 运行时。安装完成后直接打开即可使用，无需自行安装 Node。

【支持的系统】
- Windows 10（64 位）及更高版本
- Windows 11（64 位）
- 仅支持 64 位（x64）系统，不支持 32 位（x86）系统

【使用提示】
- 首次启动会初始化运行环境，请耐心等待片刻。
- DeepSeek API Key 请在客户端「设置 → 模型」中配置。
- 快捷键 Ctrl+Alt+D 可呼出/隐藏窗口。
