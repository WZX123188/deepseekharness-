# DSH 手机端（v5.0.0）

远程操作电脑上的 DSH 客户端：发指令给电脑智能体执行、浏览并下载电脑文件到手机。

## 功能

1. **发指令**：手机发文字 → 电脑端智能体执行 → 结果回传手机（智能体会把结果写入 remote-reply.txt，手机轮询读取）。
2. **文件传输**：浏览电脑目录（默认用户目录起，可进入任意盘符路径）→ 点「下载」把文件存到手机。
3. **语音输入**（v5.1.0）：对话框麦克风图标，语音转文字后发送（需要授权麦克风权限）。

## 安装 / 使用

### 安卓
- 方式一：从 GitHub Release 下载 `DSHClient-5.0.0.apk` → 手机文件管理器找到 → 安装（首次提示"未知来源"属正常，允许即可）。
- 方式二：手机浏览器直接打开 `http://<电脑IP>:3191/mobile`（无需安装）。

### 苹果 iPhone
- Safari 打开 `http://<电脑IP>:3191/mobile` → 点分享 → 「添加到主屏幕」→ 像 App 一样用（iOS 不能侧载 App，网页即 App）。

### 连接步骤（两端）
1. 电脑端：打开 DSH 客户端 → 设置 →「手机远程」→ 记下 **6 位配对码** 和 **地址**（如 192.168.1.100:3191）。
2. 手机端：打开网页/App → 输入地址 + 配对码 → 连接成功。

## 通信方式（免费、私密、安全、易复制）

| 场景 | 做法 |
|---|---|
| **同一 WiFi（局域网）** | 手机直接连 `电脑IP:3191`，本机私密，无需任何账号 |
| **人在外（跨网）** | 电脑和手机都装免费 [Tailscale](https://tailscale.com)（注册一个账号，两台设备登录同一个账号即自动组网）→ 手机连 Tailscale 分配给电脑的 IP（如 100.x.x.x:3191）|

- **私密安全**：3191 服务需要 **6 位配对码 + 随机 token** 双重认证；Tailscale 走 **WireGuard 端到端加密**，第三方无法窃听。
- **易于复制**：别人用这套 = 电脑装客户端（点开即可）→ 手机装 APK/开网页 → 输配对码。零配置服务器、零公网 IP、零费用。

## 电脑端地址说明

- 电脑端「手机远程」页会列出本机局域网 IP 列表，任选一个手机能 ping 通的即可。
- 端口固定 **3191**（可被 `DSH_REMOTE_PORT` 环境变量覆盖，用于多实例/测试）。
