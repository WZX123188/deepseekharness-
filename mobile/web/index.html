🔗 怎么让手机连上电脑

要用「Tailscale」把手机和电脑组成一个加密的虚拟局域网，人在外面也能安全直连家里的电脑。

❓ Tailscale 是什么

一款免费开源的组网工具。装上并登录同一个账号后，你的手机和电脑就像在同一 WiFi 里一样互相访问，数据走端到端加密隧道，不暴露公网、不花一分钱。

📱 一步步来

1
电脑装 Tailscale去 tailscale.com 下载 Windows 版安装，注册并登录账号。
2
手机装 Tailscale应用商店搜 Tailscale 安装，登录同一个账号。
3
确认已组网两边都登录后自动组成虚拟局域网，无需其他设置。
4
记下电脑地址电脑端 DSH 客户端 → 设置 →「手机远程」，找到 Tailscale 地址（100.x.x.x:3191），或直接用手机扫二维码。
5
手机填地址连接下一步输入该地址 + 配对码即可。

🔗 连接电脑

同一 WiFi 填局域网 IP；人在外填 Tailscale 地址（100.x.x.x）。电脑端「手机远程」页有地址和配对码，也可直接扫码。

📖 使用指南

· 接入 API：电脑端「设置 → 模型」配置 DeepSeek API Key。
· 权限门：修改/删除文件需勾选同意；读取默认放行。
· 余额/用量：查看 DeepSeek 账户余额。
· 市场：一键安装热门 Tool/Plugin，装后需「启用」才生效。
· 翻译：PDF/Office 文档翻译成中文。
· 手机远程：手机给电脑发消息、传文件、查余额，与电脑共用同一后端。
